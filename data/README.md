# Datos

El dataset completo (`reto_agua.csv`, 55.083 filas × 26 columnas, estado de bombas de agua en Tanzania) lo facilitó el curso y no se incluye en este repositorio.

- `muestra_reto_agua.csv`: muestra estratificada de unas 1.000 filas (misma estructura), solo para ver el formato y probar el código.
- Para reproducir los resultados del README, coloca el fichero completo como `data/reto_agua.csv`.
